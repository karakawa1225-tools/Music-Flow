# MUSIC FLOW インストーラー

他の Windows PC にインストールするためのセットアップ EXE が、ここに出力されます。

## 作成方法（開発PC）

プロジェクト直下で:

```bat
npm run dist
```

または:

```bat
scripts\build-installer.bat
```

## 他のPCへの入れ方

1. このフォルダ内の `MUSIC-FLOW-Setup-2.0.0.exe`（バージョンは変わる場合があります）をコピー
2. 相手のPCで EXE をダブルクリック
3. インストール先フォルダを選んで「インストール」
4. **デスクトップに「MUSIC FLOW」ショートカットが自動作成**されます
5. スタートメニューにも登録されます

## 注意

- Windows 10 / 11（64bit）向けです
- インストールに管理者権限は基本不要です（ユーザーフォルダへ入れます）
- 音楽ファイル本体はアプリ内に取り込みません（参照のみ）
- ライブラリデータは `%APPDATA%\music-flow\MUSIC FLOW\` に保存されます
